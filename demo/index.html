Prototype. The enclave boundary is simulated in software (per-bank encryption and a simulated attestation check); the production target is IBM Secure Execution for Linux. Banks B1–B5 are a consortium built from IBM's synthetic AML dataset (HI-Small, 5M transactions); no real customers. "Confirmed mule" uses the dataset's held-out test labels, which a real bank would not have at alert time. Speed on LinuxONE (3 vCPUs): each new payment is pattern-mined and scored in under 3 ms (p99), about 45,000 payments per second.
